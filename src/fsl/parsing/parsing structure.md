Each file is lexed into a vector of tokens via fsl_lexer. Tabs and spaces are lexed into a whitespace token, newlines are lexed into newline tokens, symbols are lexed into the associated symbol token, lone numbers are lexed into an integer token if they are a valid integer or into a number token otherwise, and valid identifier tokens (contains only alphanumeric tokens and/or underscores, doesn't start with a number) are lexed into either an identifier token or the associated keyword token if they match that keyword. 

After the token vector is created, fsl_parser preprocesses it, handling all preprocessor directives, expanding all macros, and removing all tokens that aren't relevant to the code (such as comments), and then outputs another token vector.

The preprocessed token vector is passed into \_collect\_scopes, which outputs a vector of TokenTrees. A TokenTree is either a Token or a TokenScope. A TokenScope has a token that marks the opening of the scope, a vector of TokenTrees representing the contents of the scope, and another token marking the closing of the scope.
